Sync to Google Calendar

This downloads a single .ics file with every event currently visible on the calendar (respecting your active filters). Import it into Google Calendar in three quick steps:

  1. 1Click Download .ics File below — it'll land in your Downloads folder.
  2. 2On Google Calendar, click the gear icon → Settings → Import & export.
  3. 3Under Import, select the downloaded file and pick which calendar to add it to, then click Import.

Prefer adding events one at a time instead? Open any event on the calendar and use its own "Add to Google Calendar" button.

Sync Time Table to Google Calendar

This downloads a single .ics file with every class currently shown for your batch (respecting your active filters), set to repeat weekly until the last day of teaching. Import it into Google Calendar in three quick steps:

  1. 1Click Download .ics File below — it'll land in your Downloads folder.
  2. 2On Google Calendar, click the gear icon → Settings → Import & export.
  3. 3Under Import, select the downloaded file and pick which calendar to add it to, then click Import.

Prefer adding one class at a time instead? Open any class on the grid and use its own "Add to Google Calendar" button.
